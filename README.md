## 게임 방법

화면 아래쪽에 있는 내 캐릭터를 움직여, 위쪽의 상대 포켓몬을 맞혀서 잡는 게임이에요.

- **제한 시간 80초**, 목숨은 **1개**예요. 상대 공격에 한 번 맞으면 게임이 끝나요.
- 상대 포켓몬을 맞히면 **잡았다! +30G**
- 강 위의 **잉어킹**을 맞히면 **+10G**. 가끔 나오는 **황금 잉어킹**은 **+100G**!
- 바위 위의 **열매**를 맞히면 잠시 동안 버프를 받아요.
  - 파란 열매: 스킬 쿨타임 감소
  - 빨간 열매: 이동 속도 증가
- 잉어킹이나 열매를 맞히면 공격 쿨타임이 바로 짧아져요. 빠르게 다음 공격을 노려 보세요.

### 조작

| 버튼 | 동작 |
|---|---|
| ◀ ▶ | 왼쪽·오른쪽으로 이동 (누르고 있는 동안) |
| 스킬 | 조준선 방향으로 공격 |
| 점멸 | 바라보는 방향으로 순간 이동 (쿨타임 5초) |
| 설정 | 일시정지, 음량 조절, 메뉴로 나가기 |

조준선은 좌우로 자동으로 움직여요. 상대가 조준선에 들어오는 순간을 노려서 공격하세요!

## 뽑기와 도감

- 게임에서 모은 골드로 **카드팩**을 살 수 있어요. 한 팩에 카드 5장이 들어 있어요.

  | 구매 | 가격 |
  |---|---|
  | 1팩 | 500G |
  | 5팩 | 2,500G |
  | 10팩 | 5,000G |
  | 30팩 | 15,000G |

- 카드 등급과 확률: **노말 50% · 레어 30% · 에픽 15% · 전설 5%**
- 카드팩을 열 때 화면을 누르면 한 장씩, 길게 누르면 빠르게 넘어가요. 에픽·전설 카드가 나오면 자동으로 멈춰요.
- **도감**에서 빈 칸을 눌러 가지고 있는 카드를 꽂을 수 있어요. 등급별로 골라 볼 수도 있어요.

---

## 캐릭터

- 카드를 뽑으면 그 포켓몬의 **조각**이 모여요.

  | 카드 등급 | 조각 |
  |---|---|
  | 노말 | 1개 |
  | 레어 | 2개 |
  | 에픽 | 5개 |
  | 전설 | 10개 |

- 조각을 **50개** 모으면 메뉴의 캐릭터 창 → **변경**에서 그 포켓몬을 캐릭터로 만들 수 있어요.
- 캐릭터마다 공격 모습이 달라요.
  - **지우**: 몬스터볼을 던져서 포켓몬을 잡아요.
  - **엠페르트**: 물줄기를 남기는 물 구슬을 쏘아요.

새 캐릭터는 계속 추가될 예정이에요.
